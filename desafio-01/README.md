# Desafio Técnico - Cálculo de Comissão

Programa desenvolvido para calcular a comissão de vendedores
com base no valor de cada venda.

## Regras

- Vendas abaixo de R$ 100,00: 0% de comissão
- Vendas de R$ 100,00 até abaixo de R$ 500,00: 1% de comissão
- Vendas a partir de R$ 500,00: 5% de comissão

## Tecnologias

- Python 3
- JSON
